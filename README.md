# Neon Drift

A small browser arcade game built with plain HTML, CSS, and JavaScript.

## Play

Open `index.html` in a browser, or enable GitHub Pages for the repository root. No build step is required.

## Controls

- **WASD / Arrow keys** — move
- **F / click** — fire
- **Space** — pause

Collect 20 cyan shards to win, avoid the pink mines, and fire to destroy them for bonus points. Your best score is saved in the browser.
